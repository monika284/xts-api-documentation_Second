    Modify Order API

    Change the details of an existing open order without canceling and re-placing it. Update quantity, price, product type, or order type on the fly.

    Edit Shopping Cart= Modify Order API
    Order Before Ship= Active Open Order
    Updated Delivery= Modified Order
    Beginner

    What is Modify Order?

    Think of it like editing an online shopping order before it is shipped. You ordered 10 notebooks at ₹100 each — before the seller ships them, you decide to increase quantity to 15 or change the price. Instead of cancelling and re-ordering, you simply edit the existing order.

    Shopping Order Edit
    Original10 notebooks @ ₹100
    Change15 notebooks @ ₹95
    ConditionNot yet shipped
    ResultSame order, updated
    ↔
    Trading Order Edit
    Original10 RELIANCE @ ₹2850
    Change15 RELIANCE @ ₹2860
    ConditionOrder not yet executed
    ResultSame order, updated

    Why is Modify Order Needed?

    Market prices changed since you placed the order
    You want to buy or sell at a different price
    You want to increase or decrease quantity
    You want to switch the order type (Limit → Market)
    Avoid cancel + re-place cycle — saves time and fees

    Intermediate

    What Can Be Modified?

    QUANTITY

    Increase or decrease the number of shares in your order.

    10 shares → 20 shares
    PRICE

    Update the limit price to match changing market conditions.

    ₹2850 → ₹2865
    ORDER TYPE

    Switch between Limit and Market order types.

    Limit Order → Market Order
    PRODUCT TYPE

    Change product type if supported by broker and exchange.

    MIS → NRML

    What Cannot Be Modified?

    Exchange Segment
    Cannot switch NSECM → NSEFO
    Trading Symbol
    Cannot change RELIANCE to TCS
    Instrument ID
    Locked at placement time
    Order Side
    Cannot flip BUY ↔ SELL

    To change any of the above, cancel the existing order and place a new one.

    Internal Working

    1User sends Modify Request — Order ID, new quantity, new price, updated params
    2Broker validates — Is the order active? Is modification allowed? Sufficient margin?
    3Request sent to Exchange — exchange receives the update
    4Existing order updated — exchange replaces old values with new values
    5Confirmation returned — Order ID, new status, and description

    Common Use Cases

    Improve Execution

    Increase the price to improve chances of the order being matched by the exchange.

    Reduce Risk

    Decrease quantity when the market becomes volatile to limit your exposure.

    Follow Market

    Adjust the limit price continuously to track changing market conditions.

    Update Stop Loss

    Move the trigger price up to lock in profits as the stock price rises.

    Advanced

    Request Parameters

    ParameterTypeRequiredDescription
    appOrderIDInteger✅ YesUnique Order ID returned when order was placed
    modifiedProductTypeString✅ YesUpdated product type: MIS, CNC, NRML
    modifiedOrderTypeString✅ YesUpdated order type: MARKET or LIMIT
    modifiedOrderQuantityInteger✅ YesNew quantity for the order
    modifiedDisclosedQuantityInteger✅ YesVisible quantity in order book (0 = show all)
    modifiedLimitPriceFloat⬜ NoNew limit price (required for LIMIT orders)
    modifiedStopPriceFloat⬜ NoNew trigger price (for Stop Loss)
    modifiedTimeInForceString✅ YesDAY or IOC
    orderUniqueIdentifierString⬜ NoYour custom tag for the order
    clientIDString⬜ NoUser account ID

    Advanced Concepts
    Partial Fill Case

    Only the remaining unfilled quantity can be modified. Already-executed shares are locked.

    Market → Limit Conversion

    Switch a Market order to Limit by providing a new limit price in the modify request.
