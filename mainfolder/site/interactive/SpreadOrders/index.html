Spread Orders

A Spread Order places two related positions (legs) simultaneously — one buy and one sell — to profit from the price difference between two instruments rather than the movement of a single one.

Two-leg order
Reduced market risk
Simultaneous execution
Price spread trading
F&O strategies
Efficient execution

Two Legs of a Spread Order

BUY LEG
Buy Leg

The instrument you want to buy.

Buy NIFTY July Future
⇄
SELL LEG
Sell Leg

The related instrument you want to sell.

Sell NIFTY August Future

How It Works

Create Spread Order

Select Buy Leg

Select Sell Leg

Sent to Exchange

Both Legs Executed

Example — NIFTY Calendar Spread

Leg Action Instrument
Buy Leg BUY NIFTY July Future
Sell Leg SELL NIFTY August Future

If the price difference (spread) between July and August contracts changes in your favor, you make a profit — even if the overall market moves only slightly.

Spread Order vs Normal Order

NORMAL ORDER
  • Single buy or sell order
  • Trades one instrument
  • Higher market exposure
  • Regular equity & derivative trading
→
SPREAD ORDER
  • Two linked orders (buy + sell)
  • Trades price difference between two instruments
  • Lower market risk
  • Futures & options strategies

Advantages & Limitations

Advantages
  • Reduces overall market risk
  • Both legs executed together
  • Suitable for F&O strategies
  • Profit from price differences
  • No need for multiple separate orders
Limitations
  • Supported on select exchanges only
  • Both instruments must be related
  • More complex than a regular order
  • Requires spread strategy knowledge

Common Use Cases

📅 Calendar Spread

Buy one month's futures and sell another month's futures contract.

🏭 Commodity Spread

Trade the price difference between two related commodity contracts.

📊 Options Spread

Combine multiple option contracts to manage risk and potential profit.

⚖️ Arbitrage Trading

Take advantage of price differences between related instruments or markets.

!!! tip

Always choose related instruments, ensure sufficient margin for both positions, and verify exchange support before placing a Spread Order.

Cancel Spread Orders (DELETE)

Cancels an existing open spread order along with all its associated legs, provided the order has not been fully executed.

DELETE https://xts.rmoneyindia.co.in:3000/interactive/orders/spread?spreadExchangeSegment=NSEFO&spreadExchangeInstrumentID=13687399&exchangeOrderID=X_174305899&orderID=12409992685&apiOrderSource=WebAPI

Request Body Parameters

Parameter Name Type Mandatory Description
spreadExchangeSegmentExchangeSegmentYExchange segment of the spread order (e.g., NSEFO)
spreadExchangeInstrumentIDExchangeInstrumentIDYSpread instrument token used for querying the order
exchangeOrderIDExchangeOrderIDNExchange-generated order identifier
orderIDOrderIDNUnique internal order ID assigned by RMS/system
apiOrderSourceApiOrderSourceNSource from where the API request originated (e.g., WebAPI)

Response Body Parameters

Parameter Name Type Description
OrderIDOrderIDUnique order ID that was deleted
