    Exchange Status

    Exchange Status shows the current operating state of a stock exchange — whether it is open, closed, halted, or in a special trading session. It helps traders know if trading is currently allowed and what phase the market is in.

    Market Hours
    Live Status
    NSE, BSE & MCX
    Session Awareness

    What is Exchange Status?

    Exchange Status indicates whether a stock exchange is currently open, closed, or in a specific trading phase. Before placing any order, traders use this to confirm that trading is available and to understand which market session is currently active.
    MARKET PHASE
    Know which trading session is currently active
    ORDER SAFETY
    Avoid placing orders when trading is unavailable
    INTERRUPTIONS
    Stay informed about halts and special sessions

    Common Exchange Status Types

    1. Open

    The exchange is open and trading is taking place normally.

    Exchange Status: OPEN
    Buy shares Sell shares Modify orders Cancel orders
    2. Closed

    The exchange is not accepting trades — market has closed or it is a holiday.

    Exchange Status: CLOSED

    No trading is possible until the next trading session.

    3. Pre-Open

    A session before regular market hours where orders can be placed but continuous trading has not started yet.

    Exchange Status: PRE-OPEN

    Orders can be entered/modified/cancelled. The exchange determines the opening price.

    4. Post-Close

    A session after regular market hours where certain activities may still be allowed.

    Exchange Status: POST-CLOSE

    Depending on exchange rules, some order-related activities may still be available.

    5. Trading Halt

    Trading has been temporarily suspended. Reasons may include:

    Corporate announcements Technical issues Regulatory actions Circuit breakers
    Exchange Status: HALTED
    6. Auction Session

    A special session used for auction-related trading, such as settling short deliveries.

    Exchange Status: AUCTION

    Only auction-related trades are processed during this session.

    7. Suspended

    Trading for a specific security has been suspended until further notice. No orders can be executed for that security until the exchange lifts the suspension.

    Exchange Status: SUSPENDED

    Exchange Status Lifecycle

    Market Closed
    ▼
    Pre-Open Session
    ▼
    Market Open
    ▼
    (Optional) Trading Halt
    ▼
    Trading Resumes
    ▼
    Market Close
    ▼
    Post-Close Session

    Example

    ⏰ 10:30 AM — Market Open
    Exchange: NSE
    Status : OPEN
    Session : Regular Trading

    You can place, modify, and cancel orders normally.

    ⏰ 3:30 PM — Market Closed
    Exchange: NSE
    Status : CLOSED

    Market has closed. New trades cannot be executed.

    Information Returned by Exchange Status API

    Field Description
    ExchangeName of the exchange (NSE, BSE, MCX, etc.)
    StatusCurrent market status — Open, Closed, Halted, Auction, etc.
    SessionCurrent trading session — Pre-Open, Regular, Auction, Post-Close
    Start TimeSession start time
    End TimeSession end time
    Last UpdatedTime when the status was last refreshed

    Why Trading Applications Use Exchange Status

    Enable or disable trading buttons based on market status
    Display market availability clearly to the user
    Prevent invalid order placement outside trading hours
    Inform users about market sessions and transitions
    Synchronize application behaviour with the exchange

    Real-Life Example

    You open a trading app at 8:45 AM.

    ⏰ 8:45 AM
    Exchange: NSE
    Status : PRE-OPEN

    You can place orders, but regular trading hasn't started yet.

    ⏰ 9:15 AM
    Exchange: NSE
    Status : OPEN

    Regular trading has begun. Orders can now be matched and executed.

    In Simple Words: Exchange Status tells you the current state of the stock exchange — such as Open, Closed, Pre-Open, Halted, or Auction — so you know whether trading is available and which market session is currently active.

    Exchange Status GET

    Exchange Status indicates the availability of eligible exchanges for normal trading. It allows users to determine whether they can place an order or not.

    URL

    GET https://xts.rmoneyindia.co.in:3000/1interactive/status/exchange?userID=RM

    Request Body Parameters

    Parameter Name Type Mandatory Description
    userID UserID Y User specific Identification

    Response Body Parameters

    Parameter Name Type Description
    exchangeSegment ExchangeSegment ↗ ExchangeSegment ↗
    exchangeMarketType MarketType ↗ MarketType ↗
    exchangeTradingSession TradingSession ↗ TradingSession ↗
