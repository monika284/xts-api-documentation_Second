Order History

Order History is a complete timeline of all orders you have placed — showing every status change from placement to execution, cancellation, or rejection.

Complete lifecycle
All status changes
Modification history
Rejection reasons
Audit & troubleshoot
Performance review

OpenActive in the exchange order book

Partially FilledPart of the order quantity has been executed
FilledOrder completely executed
Pending CancelCancellation request sent, awaiting confirmation
CancelledOrder cancelled by user or system
RejectedOrder rejected by exchange or risk management system

Order History vs Order Book

ORDER BOOK
  • Shows current status of orders
  • Primarily displays the latest status
  • Focused on active orders
  • Focuses on current order information
→
ORDER HISTORY
  • Shows complete lifecycle of an order
  • Records every event and status change
  • Useful for reviewing past activities
  • Includes modification and cancellation history

Common Use Cases

📋 Review Past Orders

Check all orders placed over a selected period.

🔄 Track Status Changes

See how an order progressed from placement to completion.

🔍 Troubleshoot Issues

Identify why an order was rejected or cancelled.

🗂️ Audit Activity

Maintain a complete record of all trading actions.

📈 Performance Analysis

Review past orders to improve future trading decisions.

!!! note Order history only shows orders from the current trading day. Historical data from previous days is not available through this endpoint.
