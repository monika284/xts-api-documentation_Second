What is Margin?

Margin is the minimum amount of funds required in your account to place or hold a trade. It acts as a security deposit to cover potential losses. The exchange sets margin requirements based on the instrument, product type, and market volatility.

Simple Example — RELIANCE MIS Trade

The calculated amount is an estimate of the funds required to place this trade successfully.

Types of Margin

S
SPAN Margin
Standard Portfolio Analysis of Risk. The minimum margin required by the exchange for F&O positions, calculated based on the worst possible loss scenario.
E
Exposure Margin
An additional buffer collected by the exchange over SPAN margin to cover mark-to-market losses and other risks not captured by SPAN.
V
VAR Margin
Value at Risk margin applies to equity cash (CNC/MIS) positions. Computed based on the stock's historical price volatility over a defined period.
E
ELM Margin
Extreme Loss Margin is collected to cover losses beyond VAR. It is a fixed percentage set by the exchange for each security.

Why Margin Matters

Avoid insufficient margin errors before placing orders
Plan trades by knowing exact fund requirements upfront
Supports Equity, F&O, Currency, and Commodity
Saves time with instant pre-trade estimates
Helps manage risk across multiple positions
Improves overall trading discipline and planning

Order Margin Details

Calculate the margin required for a new order before placing it.

ENDPOINT POST
https://xts.rmoneyindia.co.in:3000/interactive/orders/margindetails
Requires: valid Authorization token

Request Body Parameters

Parameter NameTypeMandatoryDescription
exchangeSegmentExchangeSegmentYExchange segment (e.g., NSECM, NSEFO, BSECM)
exchangeInstrumentIDExchangeInstrumentIDYToken ID of the instrument
productTypeProductTypeYProduct type — MIS, CNC, NRML
orderTypeOrderTypeYOrder type — MARKET, LIMIT, STOPLIMIT, STOPMARKET
orderSideOrderSideYBUY or SELL
orderQuantityQuantityYNumber of shares or lots
limitPricePriceYLimit price for the order (use 0 for market orders)
stopPricePriceNStop-loss trigger price (for SL orders)
clientIDClientIDNClient ID — mandatory for dealer accounts

Request Body JSON

{
  "exchangeSegment": "NSECM",
  "exchangeInstrumentID": 2885,
  "productType": "MIS",
  "orderType": "LIMIT",
  "orderSide": "BUY",
  "orderQuantity": 100,
  "limitPrice": 2850.00,
  "stopPrice": 0
}

Response Body Parameters

Parameter NameTypeDescription
typeStringResponse status — success or error
codeStringResponse code (e.g., s-margin-0001)
descriptionStringHuman-readable response message
InitialMarginAmountTotal initial margin required for the order
MarginUsedAmountMargin already utilised from the account
MarginUsedTradeAmountMargin that will be used for this specific trade
MarginAvailableAmountAvailable margin balance after placing this order
SpanMarginAmountSPAN margin component (applicable for F&O)
ExposureMarginAmountExposure margin component (applicable for F&O)
VarMarginAmountVAR margin component (applicable for equity)
ELMMarginAmountExtreme Loss Margin component

Response Body JSON

{
  "type": "success",
  "code": "s-margin-0001",
  "description": "Margin Details",
  "result": {
    "InitialMargin": 57000.00,
    "MarginUsed": 12000.00,
    "MarginUsedTrade": 57000.00,
    "MarginAvailable": 93000.00,
    "SpanMargin": 0.00,
    "ExposureMargin": 0.00,
    "VarMargin": 45600.00,
    "ELMMargin": 11400.00
  }
}

Code Examples

curl --location 'https://xts.rmoneyindia.co.in:3000/interactive/orders/margindetails' \
--header 'Authorization: xxxxxx' \
--header 'Content-Type: application/json' \
--data '{'
  "exchangeSegment": "NSECM",
  "exchangeInstrumentID": 2885,
  "productType": "MIS",
  "orderType": "LIMIT",
  "orderSide": "BUY",
  "orderQuantity": 100,
  "limitPrice": 2850.00,
  "stopPrice": 0
'}'
import requests
import json

url = "https://xts.rmoneyindia.co.in:3000/interactive/orders/margindetails"

payload = json.dumps({
  "exchangeSegment": "NSECM",
  "exchangeInstrumentID": 2885,
  "productType": "MIS",
  "orderType": "LIMIT",
  "orderSide": "BUY",
  "orderQuantity": 100,
  "limitPrice": 2850.00,
  "stopPrice": 0
})
headers = {
  'Authorization': 'xxxxxx',
  'Content-Type': 'application/json'
}

response = requests.request("POST", url, headers=headers, data=payload)
print(response.text)

Modify Order Margin Details

Calculate the margin impact when modifying an existing open order — quantity or price change.

ENDPOINT POST
https://xts.rmoneyindia.co.in:3000/interactive/orders/modifyordermargindetails
Requires: valid Authorization token

Request Body Parameters

Parameter NameTypeMandatoryDescription
appOrderIDAppOrderIDYUnique order ID of the existing order to modify
orderQuantityQuantityYNew quantity for the order
limitPricePriceYNew limit price (use 0 for market orders)
stopPricePriceNNew stop-loss trigger price
clientIDClientIDNClient ID — mandatory for dealer accounts

Request Body JSON

{
  "appOrderID": 1234567890,
  "orderQuantity": 150,
  "limitPrice": 2870.00,
  "stopPrice": 0
}

Response Body JSON

{
  "type": "success",
  "code": "s-margin-0002",
  "description": "Modify Order Margin Details",
  "result": {
    "InitialMargin": 85500.00,
    "MarginUsedTrade": 85500.00,
    "MarginAvailable": 64500.00

}
