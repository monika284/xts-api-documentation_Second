Market Data API Overview

The Market Data API provides real-time and historical market information for a wide range of financial instruments.

API Environment URLs

BASE URL
https://developers.symphonyfintech.in/apibinarymarketdata

What is Market Data?

Market data is information generated by exchanges during trading hours. It helps you track live prices, analyze trends, and make informed trading decisions.

Types of Market Data

Live Data

Real-time data received instantly from exchanges.

Example: LTP, Bid, Ask, Volume

Delayed Data

Data received with a short delay (e.g., 15 minutes).

Example: 15-min Delayed Data

Historical Data

Previously recorded data for past dates.

Example: Daily, Weekly, Monthly

Key Features

Real-time Quotes

Get the latest price, change, volume and other market details in real-time.

Historical Data

Access historical data for analysis, backtesting and trend identification.

OHLC Data

Retrieve Open, High, Low, Close data for any time interval.

Market Depth

View real-time buy and sell orders in the market depth (order book).

Instrument Info

Get details about instruments like lot size, tick size, expiry, and trading symbol.

Live & Historical

Support for both live market data and historical data retrieval.
