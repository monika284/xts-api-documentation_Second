Client Configuration

Client Configuration refers to the settings, permissions, and trading-related information associated with a specific client account — defining how a client can use the trading platform and APIs.

Trading permissions
Exchange access
Broker compliance
Product types
API access control
Custom UX settings

How Client Configuration Works

User Login
→
Config Retrieved
→
Permissions Verified
→
Features Enabled
→
App Ready

Information Available in Client Configuration

Client Details
  • User ID
  • Client Code
  • Account Type
Exchange Access
  • NSECM, NSEFO
  • BSECM, MCXFO
  • Other enabled exchanges
Product Types
  • MIS, NRML, CNC
  • BO, CO, MTF
Trading Permissions
  • Equity Trading
  • F&O Trading
  • Currency & Commodity
API Settings
  • API Access Enabled
  • WebSocket Access
  • Market Data Permissions

Example Configuration

Client Code : ABC123
Exchange Access : NSECM, NSEFO
Product Types : MIS, NRML, CNC
API Access : Enabled
WebSocket Access : Enabled

This means the client can trade in NSE Cash and F&O segments using the allowed product types.

Common Use Cases

Trading Applications

Load user-specific trading settings and preferences automatically on login.

API Access Control

Determine which APIs and endpoints the client is authorized to use.

Exchange Validation

Ensure orders are placed only in segments the client is allowed to access.

Feature Management

Enable or disable platform features based on account-level permissions.

Get Client Config GET

Retrieves the client-specific configuration including allowed exchange segments, message codes, publish format, broadcast mode, and instrument types.

URL

GET https://xts.rmoneyindia.co.in:3000//apimarketdata/config/clientConfig

Response Body Parameters

Parameter Name Type Description
exchangeSegments ExchangeSegments ExchangeSegments ↗
xtsMessageCode XTS Message Code XTS Message Code ↗
publishFormat PublishFormat PublishFormat ↗
broadCastMode BroadCastMode BroadCastMode ↗
instrumentType InstrumentType InstrumentType ↗
