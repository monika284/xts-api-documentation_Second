RMoney (XTS)

RMoney - (Raghunandan Capital Pvt Ltd) Broker Integration

RMoney is a Gandhinagar(Gujarat)-based deep discount broker that provides API access via the XTS (Symphony Fintech) platform.

Step 1: Create API Applications

Let's start by :

Once logged in:

  1. Go to My App > Create New Application
  2. Create two separate apps:
    • Interactive Order API
    • Market Data API

Details to Fill:

  • App Name: Demo
  • App Description: For demo purpose
  • Redirect URL: (leave it empty)
  • Company Name: (leave it empty or your own)
  • Choose the correct API Package depending on the app (Interactive order or Market Data).
